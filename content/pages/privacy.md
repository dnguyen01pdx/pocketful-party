---
title: Privacy
date: 2026-10-23
description: What Pocketful Party collects (very little).
---
Pocketful Party doesn't ask for your name or email, and you don't need an account to download anything.

The site is hosted on GitHub Pages, which keeps standard server logs (like IP addresses) for security. Links from Pinterest carry a tag in the web address so we can see which pin a visit came from; that tag doesn't identify you.

If we add privacy-friendly analytics, ads or an email list later, this page will be updated first and will explain what's collected and how to opt out.
